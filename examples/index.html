urlstate examples

Run pnpm build && pnpm examples, then open the pages below. Each page shows the live URL at the top; use Back/Forward to see the state restore.

Vanilla JS

  • Counter — queryState + parseAsInteger, push history
  • Debounced search — bind() with debounce
  • Filters + pagination — queryStates, urlKeys, reset page on filter change
  • Tabs — parseAsStringLiteral, Back button switches tabs
  • Declarative — data-urlstate attributes + autoBind()
  • Hash adapter — state stored in #/?...

jQuery (3.6+)

  • Single input — $(el).urlState(); switch jQuery with ?jq=3.6.0
  • Laravel-style form — $(form).urlStateForm() with brands[]
  • Select2 — widget driver
  • DataTables — page / search / sort in the URL

Node / tooling

  • examples/node/loader.mjs — createLoader on the server
  • examples/node/serializer.mjs — build links with createSerializer
  • examples/node/testing.test.ts — unit-test URL state with memoryAdapter
